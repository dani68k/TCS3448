6. INTEGRATION TIME
==================================================

La interfaz debe permitir modificar el tiempo de integración.

La librería o el TCS3448Manager puede internamente usar:
- ATIME
- ASTEP
- o una función basada en milisegundos

La web no debe conocer ATIME/ASTEP.

La web debe trabajar preferentemente con:

integration_time_ms

Ejemplo:

Integration time
[ 50.0 ] ms

El Manager debe realizar la conversión necesaria.

Si actualmente la librería no permite pasar milisegundos directamente, encapsular la conversión en TCS3448Manager.

No implementar esta conversión en Javascript.

IMPORTANTE:
el valor mostrado como "Integration Time" debe corresponder al tiempo realmente aplicado, no simplemente al solicitado.

==================================================
7. ADC FULL SCALE
==================================================

Añadir al firmware o a la capa de configuración el cálculo del ADC full scale.

Según el TCS3448:

ADC_full_scale =
(ATIME + 1) * (ASTEP + 1)

limitado a 65535.

Exponer este valor a la web en modo READ ONLY.

Ejemplo:

ADC Full Scale
[ 18000 counts ]

No debe ser editable.

Esto será utilizado más adelante para calcular ADC %.

8. LED CURRENT
==================================================

Permitir modificar la corriente del LED integrado.

Rango válido:

4 mA a 258 mA

Pasos:

2 mA

Ejemplo:

LED Current
[ 20 ] mA

Validar:
- mínimo 4
- máximo 258
- múltiplo válido de 2 mA a partir de 4 mA

Si llega un valor inválido:
- rechazarlo
- no aplicar parcialmente la configuración
- enviar un error claro a la web

En el caso concreto de trabajar con el kit de Adafruit_TCS3448 limitar la corriente a 150mA.

==================================================
15. SET CONFIG / APPLY
==================================================

La web tendrá un botón:

[ APPLY ]

Funcionamiento:

1. usuario modifica parámetros
2. Javascript crea mensaje de configuración
3. envía configuración por BLE
4. ESP32 valida TODOS los parámetros
5. si todo es válido:
   - aplica la configuración
6. ESP32 devuelve configuración activa
7. web actualiza valores
8. mostrar confirmación

Ejemplo:

Configuration applied successfully

No asumir éxito antes de recibir ACK del ESP32.
