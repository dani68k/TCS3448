Proyecto:
Aplicación web BLE para control y lectura del sensor TCS3448 sobre ESP32.

Entorno:
- ESP32
- PlatformIO
- Arduino framework
- VSCode
- Web Bluetooth
- TCS3448Manager ya implementado
- BLE Web ya funcional
- Hito 4 funcional o en desarrollo
- La interfaz actual funciona, pero visualmente sigue siendo una interfaz de debug

OBJETIVO DE ESTE CAMBIO
=======================

Transformar la interfaz web actual en una UI con aspecto de:

- instrumento de laboratorio
- equipo de medida
- interfaz científica profesional
- diseño técnico
- dark mode

IMPORTANTE:
Este cambio es principalmente VISUAL / UX.

NO quiero modificar innecesariamente:
- protocolo BLE
- comandos
- JSON
- características BLE
- lógica de adquisición
- TCS3448Manager
- configuración del sensor
- mapping de canales
- flujo START / STOP
- lógica de conexión
- firmware salvo cambios mínimos estrictamente necesarios

La funcionalidad actual debe seguir funcionando.

NO implementar todavía:
- histogramas
- gráfica espectral real
- normalización ADC %
- transmitancia
- absorbancia
- DARK
- REFERENCE
- SAMPLE
- curvas de calibración
- análisis avanzado

El objetivo es SOLO:
1. separar Measurement y Setup en páginas distintas
2. cambiar el diseño a dark mode
3. dar aspecto de instrumental device
4. mejorar jerarquía visual
5. mantener la funcionalidad existente
6. mantener documentación actualizada

IMPORTANTE:
NO debe aparecer ninguna referencia a "otros proyectos" en:
- código
- interfaz
- comentarios
- documentación
- nombres de archivos
- clases
- textos visibles

==================================================
1. PRINCIPIO DE DISEÑO
==================================================

La aplicación debe dejar de parecer:
- página web de debug
- formulario Bootstrap genérico
- consola de desarrollo

Y debe parecer:
- instrumento de laboratorio
- software de equipo de medida
- panel de control científico
- interfaz técnica limpia y profesional

Evitar:
- colores chillones
- estilo gaming
- neón exagerado
- estética cyberpunk
- sombras excesivas
- bordes por todas partes
- demasiados recuadros anidados

Buscar:
- dark mode elegante
- azul marino / azul grisáceo
- cian/azul técnico
- verde para estados OK
- rojo únicamente para error/saturación
- amarillo/ámbar para warning
- tarjetas limpias
- controles consistentes
- tipografía legible
- valores de medida con buena jerarquía
